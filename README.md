# 📺 个人电视与影视聚合配置 (TV & VOD Config)

本仓库提供纯净切片点播源与全套电视台直播源，适用于 **iOS (uz 影视 / TVS / APTV)** 与 **Android / TV (TVBox / 影视仓 / OK 影视)**。

---

## ⚡ 核心特点

1. **纯切片直链秒播**：全部基于标准 MacCMS JSON 采集接口，无任何安卓 `.jar` 爬虫依赖，全平台通用（iOS/安卓/电脑/电视）。
2. **免网盘扫码**：无夸克/阿里等网盘转存风控限制，点击即播。
3. **国内外加速镜像**：支持 GitHub 原生地址与高速镜像反代直链。

## 📱 导入指引

### uz 影视 (iOS)
1. 复制上方 **uz 影视视频源** 的高速直链；
2. 打开 uz 影视 ➔ 底栏 **【设置】** ➔ **【数据管理】** ➔ **【视频源】**；
3. 点击右上角 **`+` 号** ➔ 粘贴链接 ➔ 确定；
4. 直播源同理：进入 **【数据管理】** ➔ **【直播源】** ➔ 粘贴上方直播源链接即可。

### TVBox / 影视仓 / OK 影视 / TVS
1. 复制上方 **标准 TVBox 配置** 链接；
2. 打开软件 ➔ **【设置】** ➔ **【配置地址】/【订阅】** ➔ 粘贴链接保存即可。
